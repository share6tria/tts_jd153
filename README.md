# tts_jd153

**给语音合成工程师·回归集与线上样本的差分算一个特征指纹并定位可疑片段。**

`tts_jd153` —— 通过字符级与结构级特征识别语音合成工程师·回归集与线上样本的差分的痕迹，给出密度与命中位置

- 零依赖，Python 3.10+ 标准库即可运行
- 单文件，`tts_jd153.py` 拷走就能用
- 不联网、不写文件

## 对应的岗位

- 目标岗位：**零一万物 · 资深语音合成工程师**
- 技能主线：语音、Python、推理加速
- 领域标签：语音
- 研究方向：语音合成工程师·回归集与线上样本的差分

工具里的规则表就是照着上面这条岗位要求建的——每条规则都挂在技能线或领域标签上，命中时能指回具体要求。

## 安装

零依赖，Python 3.10+ 即可：

```bash
pip install share6tria-tts_jd153
```

装完直接用命令名调用：

```bash
tts_jd153 --help
```

也可以不用安装，直接把 `tts_jd153.py` 拷走用——它只依赖标准库。

## 为什么需要它

只做特征匹配不做语义判定，所以不会被同义改写绕过

它遵守下面几条自己定的规矩：

1. **只报告能定位到具体位置的结论**，不做语义猜测。
2. **规则表公开**，每条命中都能对应到岗位要求的一条明示规则。
3. **输入为空或格式不对时明确报错**，不静默返回空结果。

## 用法

```bash
python tts_jd153.py --file input.txt
python tts_jd153.py --text "示例内容"
python tts_jd153.py --file input.txt --json
```

加 `--json` 可以拿到机器可读的结果，便于接到流水线里。

## 已知局限

- 相似度按字符与词估算，不等于向量相似度。
- 不联网，不做语义检索。

## 跑测试
